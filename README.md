# 👶 지원루틴 (Jiwon Routine Manager)

> **안지원 (2026.07.07 출생)** 을 위한 스마트 육아 스케줄 & 주기적 루틴 관리 웹앱

---

## 🌟 주요 기능

1. **아기 맞춤 D-Day & 성장 개월 수**
   - 상단에서 지원이의 생후 일수(D+OO일)와 개월수를 실시간 자동 계산하여 표시합니다.
2. **주기적 루틴 To-Do 관리 (완료일 기준 +N일 계산)**
   - 브레짜 내부 세척(주 1회), 브레짜 물 교체(매일), 열탕 소독(3일마다) 등
   - 완료 체크 시 **"누가 완료했는지(경술 💙 / 지은 💖)"** 선택 기록
   - 완료 시점으로부터 자동으로 다음 주기가 계산되어 갱신됩니다.
3. **지연된 일(Overdue) & 다가오는 일(D-Day) 한눈에 파악**
   - 주기를 넘긴 할 일은 붉은색 경고와 펄스 애니메이션으로 깜빡임을 방지합니다.
4. **인터랙티브 월간 캘린더**
   - 날짜별로 과거에 완료한 사람(경술/지은 뱃지)과 앞으로 예정된 할 일을 달력에 시각화합니다.
5. **담당자 원터치 필터**
   - [전체 보기], [경술 💙], [지은 💖] 버튼으로 본인 담당 업무만 모아볼 수 있습니다.
6. **향후 확장 탭 구조 완비**
   - 🍼 **타임로그** (수유, 수면, 기저귀, 이유식 기록)
   - 📊 **성장 기록** (키, 몸무게 및 백분위 곡선)
   - 📖 **육아 일기** (포토 타임라인)
7. **PWA (Progressive Web App) 지원**
   - 아이폰, 아이패드, 갤럭시에서 **"홈 화면에 추가"** 시 앱스토어 앱처럼 전체 화면으로 작동합니다.
   - 브라우저 로컬 저장소(LocalStorage)에 데이터가 안전하게 자동 저장되며, JSON 백업/복원도 지원합니다.

## 🚀 사용 방법

### 1) 내 컴퓨터(맥)에서 바로 열어보기
터미널에서 현재 폴더로 이동 후 아래 명령어를 입력합니다:
```bash
python3 -m http.server 3000
```
그 후 브라우저(Chrome, Safari 등)에서 **`http://localhost:3000`** 으로 접속하시면 바로 동작합니다.

### 2) 집 안의 패드(iPad)나 스마트폰으로 접속하기
1. 맥과 패드(아이폰)가 **같은 Wi-Fi**에 연결되어 있는지 확인합니다.
2. 맥의 터미널에서 내 IP를 확인합니다:
   ```bash
   ipconfig getifaddr en0
   ```
   (예: `192.168.0.15` 처럼 나옵니다)
3. 패드나 폰의 Safari 브라우저에서 **`http://192.168.0.15:3000`** 으로 접속합니다.
4. Safari 하단(또는 상단) 공유 버튼(네모에 화살표 위로 된 아이콘)을 누른 뒤 **[홈 화면에 추가]**를 누르면, 패드 바탕화면에 귀여운 '지원루틴' 앱 아이콘이 생겨 언제든 탭 한 번으로 열립니다!

## 🌐 GitHub Pages로 전 세계 어디서든 접속하기 (무료 웹 호스팅)
밖에서도 패드나 폰으로 접속할 수 있게 GitHub에 올리려면:
1. GitHub 웹사이트에서 새 저장소(New Repository)를 생성합니다 (예: `jiwon-project`).
2. 터미널에서 다음 명령어를 실행하여 소스코드를 올립니다:
   ```bash
   git remote add origin https://github.com/<본인-GitHub-아이디>/jiwon-project.git
   git branch -M main
   git push -u origin main
   ```
3. GitHub 저장소의 **Settings > Pages** 메뉴에서 Source를 `Deploy from a branch (main / root)`로 지정하고 저장합니다.
4. 1~2분 뒤 **`https://<본인-GitHub-아이디>.github.io/jiwon-project`** 주소가 생성되어 두 분의 폰과 패드에서 언제 어디서든 접속하실 수 있습니다!
